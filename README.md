# 🧮 Calculator

A responsive calculator web application developed using **HTML**, **CSS**, and **JavaScript**. This project provides a clean and modern interface for performing basic arithmetic calculations.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear (C) button
- Delete (⌫) button
- Responsive design
- User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
Calculator/
│── index.html
│── style.css
│── script.js
└── README.md
```

## 🎯 Learning Objectives

- Build an interactive web application using JavaScript.
- Practice DOM manipulation and event handling.
- Improve responsive web design skills using CSS.
- Understand arithmetic operations and user input handling.
